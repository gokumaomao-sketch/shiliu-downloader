拾流下载器 — Chrome / Edge 扩展安装

安装前
1. 先启动拾流下载器；macOS 打包版的扩展目录位于拾流下载器.app/Contents/Resources/browser_extension。
2. 主窗口应显示浏览器服务已连接，端口为 7374。

Chrome
1. 地址栏打开 chrome://extensions
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择设置页显示的 browser_extension 文件夹；从源码运行时位于项目根目录。
5. 确认扩展卡片显示 拾流下载器 2.1.0。

Edge
1. 地址栏打开 edge://extensions
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择设置页显示的 browser_extension 文件夹；从源码运行时位于项目根目录。

使用
1. 刷新已经打开的视频网页并播放几秒。
2. 点击视频旁的“下载视频”按钮，或浏览器工具栏中的 拾流下载器图标。
3. 如果同时装过旧版 拾流下载器扩展，请先停用旧版，避免重复按钮和重复任务。

登录信息权限
- “允许使用当前网站的登录信息”默认关闭。
- 仅当某个网站必须登录后才能解析时再开启。
- 开启后，扩展会把当前网站 Cookie 发送给本机拾流下载器，用于本次解析或下载；不会写入任务历史。

排查
- 显示未连接：确认桌面软件正在运行，端口为 7374。
- 网页没有按钮：刷新网页，确认扩展已启用并允许访问该网站。
- YouTube 只有 360p：播放几秒后重新读取；仍无其他画质通常是 YouTube 当前会话只提供 SABR 或限制了下载地址。
- 浏览器升级或移动软件目录后，可能需要重新加载 browser_extension 文件夹。
