# V2.1.2 验证范围与已知基线

## 通过

- Python 3.14 主程序 import、全部 Python AST、扩展 JS 语法与 Chrome manifest 构建。
- 505 项下载引擎、API Origin/Host 防护、任务/状态/持久化/媒体/浏览器等必要测试通过，1 项按条件跳过。
- 主窗口交互等 23 项通过；5 个 JavaScript 路由/识别测试入口通过。

## 已知失败，未改变业务以绕过

- 2 个 GUI 断言仍期待旧状态栏 36px、旧 Semibold token，与已验收的 33px/Medium 现状不符。
- 3 个模拟第二显示器定位断言受当前 macOS 实际屏幕窗口约束影响。
- test_ytdlp_opts 的旧 YouTube player_client 断言期待当前实现不提供的 extractor_args。
- 最初 2 个 Host 防护测试被系统代理改写为 502；测试进程 NO_PROXY=* 后 403 防护断言通过，未修改 API。

因此不宣称全量测试全绿。完整测试与上述失败均保留，未升级依赖或修改业务/UI。

## 数据隔离

已有测试夹具后台写入曾落入实际任务目录。本轮已恢复迁移验收保存的完整历史与原配置，未改下载文件。新增 scripts/run_tests_isolated.py 在导入程序路径前将 Path.home 仅在测试进程映射到独立临时目录；不修改环境 HOME，不改变程序运行路径或生产代码。所有后续测试使用此入口，避免用户数据写入。

```bash
NO_PROXY='*' no_proxy='*' python scripts/run_tests_isolated.py --ignore=tests/test_ytdlp_opts.py --ignore=tests/test_gui.py --ignore=tests/test_dialog_placement.py
NO_PROXY='*' no_proxy='*' python scripts/run_tests_isolated.py tests/test_gui.py -k 'not main_window_status_bar_keeps_its_height and not final_font_tokens_cover_main_and_dialogs'
```

原始用户数据、真实任务 URL、日志和本机验收证据均不随源码公开。
