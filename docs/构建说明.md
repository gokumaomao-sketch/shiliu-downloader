# V2.1.2 构建说明

目标为 macOS 12+ arm64。本轮环境：macOS 26.5.2、Python 3.14、PyInstaller 6.22.3、Apple clang 17.0.0、make 3.81。使用带 Tk 的 Python；依赖来自 requirements.txt，不升级业务依赖。

## FFmpeg

```bash
bash scripts/build_ffmpeg_macos.sh /tmp/shiliu-ffmpeg-build
```

构建目录必须独立且尚无 build 子目录。下载官方 9.0.2 源码并核验固定 SHA256。所有 configure 参数在脚本中；不用第三方预编译 FFmpeg，也不引入外部编解码库。相同来源和参数可重复执行；不同编译器/签名条件不保证字节级相同 SHA256。

## App

在独立的源码工作副本准备以下资源（不提交到 Git）：

- `third_party/macos_arm64/bin/node`：官方 24.21.0 arm64 包，按 MAC_BINARY_PROVENANCE.md 校验。
- `third_party/macos_arm64/bin/ffmpeg`、`ffprobe`：上述 install/bin 内构建结果。
- `third_party/wx_video_download`：上游 v260907 arm64 二进制，完整 MIT + Commons Clause 随包；仅免费分发。
- `third_party_sources/ffmpeg-9.0.2.tar.xz`、构建脚本、说明：对应源码与可重建资料。

```bash
python -m pip install -r requirements.txt 'pyinstaller==6.22.3'
python -m PyInstaller --noconfirm --distpath /tmp/shiliu-dist --workpath /tmp/shiliu-build 拾流下载器-macos.spec
```

spec 包含扩展、图标、许可、二进制与对应 FFmpeg 源码。ZIP 使用 ditto 保留 bundle 与权限；DMG 使用 hdiutil，卷内 App 及 Applications 入口。SHA256 校验最终 ZIP/DMG 与包内工具。
